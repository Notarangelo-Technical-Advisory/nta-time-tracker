# Contributing

This app follows the shared engineering standards in [`docs/standards/`](docs/standards/README.md).

- **Branches, commit messages and versions:** [`docs/standards/git-and-commits.md`](docs/standards/git-and-commits.md). commitlint checks the commit type when you commit.
- **Tests:** [`docs/standards/testing.md`](docs/standards/testing.md). Run `npm run test:all` before `git ship`.
- **Rules for this app only:** [`AGENTS.md`](AGENTS.md).
